# Layouts

Each value maps to an upstream `M3CarouselType`.

- `hero`: one large item with small peeking neighbors.
- `contained`: items stay contained in the content area.
- `uncontained`: items scroll to the container edge.
- `uncontainedMultiAspect`: uncontained items with their own widths.
- `fullScreen`: one edge to edge item, scrolled vertically.
